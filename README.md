# regInspect

A [jamovi](https://www.jamovi.org) module that clones jmv's **Linear Regression** analysis and adds
scatter plots throughout:

- **Estimated Marginal Means plots** gain the analysed observations (partial residuals by default,
  so the cloud stays correct on the plot's adjusted scale under a multiple regression -- identical
  to the raw dependent variable with a single predictor -- or raw values on request), plus a
  prediction interval alongside the existing confidence interval.
- A separate **Plots** tab adds descriptive, model-free views of the analysed variables: the
  dependent variable against each covariate and by each factor (both annotated with a fitted line,
  r, p and the equation), an optional colour-by-group factor with per-group lines, and a
  scatterplot matrix -- independent of the model blocks, so it works even before one is built.

Everything else (blocks/model builder, fit measures, coefficients, assumption checks, marginal
means tables, saved output columns) is jmv's, unchanged.

Appears in jamovi's menu as **Regression > Regression Inspector**. Requires jamovi >= 1.0.8.

### Spanish and Catalan translations

Ship with the module (`regInspect/jamovi/i18n/`), covering the panel, tables and plots.

## Installation (sideload)

Prebuilt `.jmo` files are attached to the [Releases](../../releases) page, one release per
jamovi/R version:

- **R 4.5.3** — jamovi builds bundling R 4.5.3
- **R 4.6.0** — jamovi builds bundling R 4.6.0

Each release has assets for macOS (arm64/x64), Windows (x64), and Linux (arm64/x64). Pick the file
matching your OS and jamovi's bundled R version, then in jamovi: **Modules -> jamovi library ->
Sideload** and select the downloaded `.jmo`.

Not sure which R version your jamovi bundles? Check **Help -> About** in jamovi.

## Repository layout

- `regInspect/` — R package source (analysis definitions, R code, jamovi UI yaml, `es`/`ca`
  translations)
- `tools/` — build, install and release helper scripts
- `dist/` — packaged `.jmo` build output per R version/OS/arch, generated by
  `tools/prepare-jmo.sh`/`tools/release.sh` (not tracked in git; attached to releases)

## Building

```
bash tools/install.sh desktop   # builds regInspect/regInspect_<version>.jmo and installs it
                                 # into jamovi.app (macOS), using the active R
bash tools/install.sh docker    # same, into a running `jamovi` Docker container (needs jmc)
bash tools/install.sh           # both, whichever are available
```

Then repackage for other jamovi/R versions and ship a release:

```
bash tools/prepare-jmo.sh 4.6.0 all     # metadata-only repackage into dist/
bash tools/release.sh 4.6.0             # + publish a GitHub release with those assets
```
